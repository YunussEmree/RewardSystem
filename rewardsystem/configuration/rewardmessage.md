# RewardMessage

You can edit the message you want fully.





Radius: If it is far from the mob by tje specified distance, the message will not be displayed.

If radius option is -1, The message will be displayed for all the players



Placeholders:

%top\_name\_x% -> x. most damager name

%top\_damage\_x% -> x. most damager damage

%personal\_damage% ->  calculated damage for each player\
