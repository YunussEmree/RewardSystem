# Features

## Core Features
- **Fully configurable** reward system
- **PlaceholderAPI support** for dynamic content
- **24/7 active Discord support** and responsive developers
- **Works with all custom mob plugins** - universal compatibility
- **WorldGuard support** for region-specific rewards

## Reward System
- Flexible **command-based rewards**
- **Chance-based rewards** with percentage customization
- **Damage-based reward tiers** for top contributors
- **Last-hit rewards** for final blow players
- **Participation rewards** for all involved players

## Advanced Features
- **Robust mathematical expression** evaluation for dynamic rewards
- **Advanced error handling** for increased stability
- **Safe fallback mechanisms** for all command types
- **Simplified configuration options** for chance-based rewards
- **Support for all placeholders** in mathematical calculations
- **Custom cooldown system** per mob type
