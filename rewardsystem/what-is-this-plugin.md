# What is this plugin?

You have a boss plugin that doesn't support rewards? You want to give special prizes to people who killed special mobs? Then this plugin is for you! RewardSystem allows you to set unlimited mobs and rewards with full customization capabilities.

## New Dynamic Rewards System

RewardSystem now includes a powerful mathematical expression system that allows you to create truly dynamic rewards. You can use player statistics, mob damage values, and any other placeholders to calculate item amounts and chance percentages.

For example, reward players based on:
- Their level (higher level = better rewards)
- Their damage contribution to the mob (more damage = better loot)
- Server statistics (player count, economy factors)
- Time-based variables (more valuable items during events)
- And much more!

All of this comes with robust error handling that ensures your rewards will work reliably even when expressions aren't perfect. The plugin's intelligent fallback system guarantees that players always receive appropriate rewards.
